# AI Stock Trading Strategy - 量化交易策略

## 问题诊断（第一周 03/11-03/13）
- 胜率：0/6 = 0%（6笔全部止损）
- 平均亏损：-$5.28/笔
- 核心问题：
  1. 纯动量追涨（dp > 0.5%），没有趋势判断
  2. 固定 2% 止损太紧，正常波动就被洗出
  3. 没有市场环境判断（熊市还在激进买入）
  4. 开盘就买，容易被早盘假突破骗

---

## 策略改进

### 1. 市场环境过滤（Market Regime Filter）
每次交易前先扫描全部16只股票，统计市场情绪：
- `green_count` = dp > 0 的股票数量
- `market_score` = green_count / 16

**规则：**
- market_score >= 0.6（10/16 以上绿）→ 正常买入，最多3笔
- market_score 0.4-0.6（7-9只绿）→ 谨慎，最多1笔，只买最强
- market_score < 0.4（6只以下绿）→ **不买入**，等待市场企稳

### 2. 入场条件（Entry Rules）
必须同时满足以下条件才考虑买入：

**基础条件：**
- dp > 0.5% 且 dp < 3%（有动量但不追涨）
- c > o（日内上涨确认）
- market_score >= 0.4（市场不是全面下跌）

**位置过滤：**
- `day_position` = (c - l) / (h - l)
- day_position > 0.5（价格在日内区间上半部分，说明有支撑）
- day_position < 0.9（不在最高点追入）

**波动率过滤：**
- `intraday_range` = (h - l) / o × 100
- intraday_range < 5%（波动过大说明不稳定，不入场）

**时间过滤：**
- 不在 06:30-07:00 买入（开盘30分钟假突破多）
- 不在 12:30-13:00 买入（尾盘波动大）
- 最佳买入窗口：07:00-11:00

### 3. 动态止损止盈（Dynamic SL/TP）
根据股票价格和波动率调整：

**止损（Stop Loss）：**
- 基础止损 = 入场价 × 0.97（-3%，比之前的2%更宽）
- 如果 intraday_range > 3%（高波动股），止损 = 入场价 × 0.96（-4%）
- 最低不超过 -5%

**止盈（Take Profit）：**
- 基础止盈 = 入场价 × 1.05（+5%）
- 如果 dp > 1.5%（强势股），止盈 = 入场价 × 1.07（+7%）

**移动止损（Trailing Stop）：**
- 当浮盈 >= 2% 时，将止损上移至入场价（保本止损）
- 当浮盈 >= 3% 时，止损上移至入场价 × 1.01（锁定1%利润）
- 当浮盈 >= 4% 时，止损上移至入场价 × 1.02（锁定2%利润）

### 4. 仓位管理（Position Sizing）
- market_score >= 0.6：单笔 12% 资金
- market_score 0.4-0.6：单笔 8% 资金（减小风险敞口）
- 单只股票最多持有 15% 总资金
- 同行业最多2只（避免集中风险）

### 5. 价格历史追踪（Price History）
创建 `price_history.json` 文件，每天收盘保存16只股票的收盘价。
积累5天数据后可计算：
- **5日均线**：判断短期趋势
- **趋势方向**：连续3天收盘走高 = 上升趋势
- **买入条件追加**：c > 5日均线（顺势交易）

### 6. 日内多次确认（Confirmation）
第一次发现符合条件的股票时 **不立即买入**，标记为候选。
下一个5分钟周期再次检查：
- 如果仍然符合条件且价格 >= 上次价格 → 确认买入
- 如果价格回落 → 取消候选

通过 `trading_state.json` 中新增 `candidates` 字段追踪：
```json
"candidates": [
  {"ticker": "INTC", "first_seen_price": 45.91, "first_seen_time": "2026-03-16 07:05 PDT"}
]
```

### 7. 每日亏损限制（Daily Loss Limit）
- 当日已实现亏损达到 -$20 时，**停止买入**
- 只监控现有持仓的止损/止盈
- 防止在坏日子里连续亏损

## 实施优先级

| 优先级 | 策略 | 难度 | 预期效果 |
|--------|------|------|----------|
| P0 | 市场环境过滤 | 低 | 避免在熊市买入（本周主要问题）|
| P0 | 动态止损 3% | 低 | 减少被正常波动洗出 |
| P0 | 时间过滤 | 低 | 避开假突破高发时段 |
| P1 | 移动止损 | 中 | 锁定利润，提高胜率 |
| P1 | 日内位置过滤 | 低 | 不追高 |
| P1 | 每日亏损限制 | 低 | 风控 |
| P2 | 二次确认 | 中 | 减少假信号 |
| P2 | 价格历史追踪 | 中 | 趋势判断 |

## Cron Job 新增步骤

在第5步（获取股价）之后，第8步（评估买入）之前，新增：

### 第5.5步 - 市场环境评估
```
统计所有16只股票：
green_count = 0
for each stock:
  if dp > 0: green_count++
market_score = green_count / 16

输出: "市场情绪: {green_count}/16 绿 (score: {market_score})"
```

### 第7.5步 - 移动止损检查
```
遍历 positions:
  profit_pct = (current_price - entry_price) / entry_price
  if profit_pct >= 0.04: new_stop = entry_price × 1.02
  elif profit_pct >= 0.03: new_stop = entry_price × 1.01
  elif profit_pct >= 0.02: new_stop = entry_price (保本)

  if new_stop > current stop_loss:
    更新 stop_loss = new_stop
    记录: "移动止损: {ticker} SL 上调至 {new_stop}"
```

### 修改第8步 - 评估买入
```
原条件 + 新增：
- market_score >= 0.4
- 当前时间在 07:00-11:00
- day_position 在 0.5-0.9
- intraday_range < 5%
- daily_loss > -$20
- 止损改为 price × 0.97
```
