## 第一阶段：Node.js 技术分析（本周末）
> 目标：给现有系统加上技术指标，不改架构

### 要做的事
1. **写 `analyze.js` 脚本**
   - 用 Yahoo Finance 免费 API 拉 30 天历史 K 线
   - 计算 RSI（14日）→ <30 超卖可买，>70 超买不追
   - 计算 5 日 / 20 日均线 → 价格在均线上方 = 上升趋势
   - 计算 MACD → 金叉 = 买入信号，死叉 = 卖出信号
   - 计算 ATR（14日）→ 动态止损（2倍ATR）
   - 输出 JSON 格式的交易信号

2. **修改 cron 交易流程**
   - 买入前先跑 `node analyze.js TICKER`
   - 只有技术指标确认才买入
   - 止损止盈根据 ATR 动态设置

3. **预期效果**
   - 过滤掉大部分假信号
   - 止损不再固定，适应每只股票的波动特征
   - 顺势交易，不逆势硬买

### 完成标准
- [ ] analyze.js 能输出16只股票的 RSI、均线、MACD、ATR
- [ ] cron 流程集成技术分析
- [ ] 第二周开始用新策略交易

## 第二阶段：独立 Node.js 交易机器人（下周）
> 目标：摆脱 Claude cron，省 token，提高稳定性

### 要做的事
1. **写 `trader.js` 主程序**
   - 独立运行，不依赖 Claude
   - 每 5 分钟自动执行交易逻辑
   - 集成技术分析（从第一阶段的 analyze.js）
   - 自动读写 trading_state.json、trade_log.txt

2. **用 Node.js 定时器代替 Claude cron**
   - `setInterval` 或 `node-cron` 包
   - 后台运行：`pm2` 或 Windows 任务计划程序
   - 不怕关窗口，不会3天过期

3. **交易信号评分系统**
   - RSI 信号：+1/-1 分
   - 均线信号：+1/-1 分
   - MACD 信号：+1/-1 分
   - 市场情绪：+1/-1 分
   - 总分 >= 3 才买入（多因子确认）

### 预期效果
- 日常交易 0 token（全自动）
- Claude 只在修改策略、看报告时使用
- 更稳定，7×24 后台运行
- 多因子验证，减少错误交易

### 完成标准
- [ ] trader.js 能独立运行完整交易周期
- [ ] 后台运行不中断
- [ ] 连续3天无人干预正常交易

## 第三阶段：Python 量化平台（第3-4周）
> 目标：回测验证策略，用数据说话

### 要做的事
1. **安装 Python 环境**
   - Python 3.11+, pip
   - yfinance, pandas, numpy, matplotlib
   - backtrader（回测框架）

2. **历史回测系统**
   - 用过去 1 年数据回测当前策略
   - 得出胜率、最大回撤、夏普比率
   - 对比不同参数组合（RSI 14 vs 21，止损 2% vs 3% vs ATR）
   - 找出最优参数

3. **策略优化**
   - 根据回测结果调整参数
   - 测试新策略：均值回归、突破交易、配对交易
   - A/B 对比不同策略的历史表现

4. **可视化报告**
   - matplotlib 画收益曲线
   - 标注每笔交易的买卖点
   - 生成 HTML 报告

### 预期效果
- 策略有数据支撑，不再拍脑袋
- 知道策略的历史胜率和风险
- 参数优化过，不再用默认值
- 用好的策略替换差的策略

### 完成标准
- [ ] 能回测至少 1 年数据
- [ ] 输出胜率、回撤、夏普比率
- [ ] 至少对比 3 种策略，选出最优

## 第四阶段：机器学习（第5周+，可选）
> 目标：用 ML 模型辅助预测

### 可能的方向
1. **特征工程**
   - 技术指标作为特征（RSI, MACD, 均线, ATR, 成交量）
   - 市场情绪特征（大盘涨跌、板块强弱）
   - 时间特征（周几、月初月末）

2. **简单模型**
   - Random Forest / XGBoost 分类器
   - 预测：未来 1 天涨/跌概率
   - 不追求高准确率，55% 就有价值

3. **集成到交易系统**
   - ML 信号作为额外的评分因子
   - 不完全依赖 ML，和技术指标结合使用

### 注意
- 金融 ML 容易过拟合，必须用样本外数据验证
- 不要期望 ML 能预测市场，只是多一个参考维度
- 简单模型往往比复杂模型更实用
